**Beschreibung**

Auf Y 69 legst du den Boden des Erdgeschosses im Schachmuster aus Terrakotta und hellem Marmor. Eine Wendeltreppe aus Pietra serena um einen Kern von 3 × 3 Blöcken führt in der Empfangshalle des Hinterhauses vom Erdgeschoss bis ins oberste Geschoss (Y 92).

**Tipp**

Ein Feld ist drei Blöcke groß. Pro Viertelumlauf steigt sie drei Blöcke, in den Ecken liegen Podeste.

**Achtung**

Die Lichtfelder setzt erst Bautüte 5. Über Stufen und Podesten bleiben drei Blöcke frei.

**Fakt**

Das Schachmuster ist eine Gestaltungsannahme (Stufe C). Eine Wendeltreppe ist die einfachste Treppe, die alle Geschosse auf kleiner Fläche verbindet; sie ist hier eine Annahme (Stufe C).
