**Beschreibung**

Der Hof bleibt offen; sein Boden aus Pflaster liegt auf Y 66. Eine Wendeltreppe aus Pietra serena um einen Kern von 3 × 3 Blöcken führt vom Erdgeschoss bis ins oberste Geschoss (Y 86).

**Achtung**

**Fakt**

Der Chiostro degli Uomini mit seinen Säulengängen liegt gleich hinter der Loggia. Die Treppe ist im Modell vereinfacht.
