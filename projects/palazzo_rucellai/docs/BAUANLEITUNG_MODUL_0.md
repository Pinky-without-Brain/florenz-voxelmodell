**Beschreibung**

Der Hof bleibt offen; sein Boden aus Pflaster liegt auf Y 60. Eine Wendeltreppe aus Pietra serena um einen Kern von 3 × 3 Blöcken führt vom Erdgeschoss bis ins oberste Geschoss (Y 97).

**Tipp**

Nur der Boden, kein Dach. Pro Viertelumlauf steigt sie drei Blöcke, in den Ecken liegen Podeste.

**Achtung**

Hier entsteht nichts in die Höhe. Über Stufen und Podesten bleiben drei Blöcke frei.

**Fakt**

Der kleine Hof liegt hinter dem Eingang. Die Treppe ist im Modell vereinfacht.
